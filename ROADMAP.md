# Roadmap

The alpha generates a Next.js repo from one of three presets, with Cursor and Claude Code context included.

## After launch

- `add <pack>` applies one pack to an existing repo.
- `sync` updates packs and merges local edits inside `seedlayer` marker blocks.
- A community preset folder, JSON files only, loaded by the same schema.
- More stacks. Database and auth stay out until the current presets stay boring to change.
- Codex and Copilot targets, each with its own thin wrapper over the same rule bodies.
- Optional ticket-to-PR commands for Jira or Linear.

## Not planned

Generating a monorepo. The schema will grow a field for that only after a single app is the default people trust.
