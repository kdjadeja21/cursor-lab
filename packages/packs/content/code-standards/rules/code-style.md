title: Code style
description: Follow the file cap, folder layout, naming, and error style
alwaysApply: true
---

Read CODE_STYLE.md before adding a file.

Stay under the file line cap. Split a file instead of asking for an exception.

Match the folder layout and file naming already in the repo. Match the error style too: either thrown errors or `Result`, not a mix.

Do not add `any`. Do not add an inline import.
