Use the slash commands that exist in this repo. Skip a command that was not generated.

`/plan` writes the approach and does not edit source. `/implement` makes the change. `/review` checks the diff and does not merge.

MCP servers start empty in `.mcp.json` and `.cursor/mcp.json`. Add a server there when a task needs one. Do not invent credentials.
