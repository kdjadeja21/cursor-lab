---
title: Short context
description: Keep AGENTS.md as an index and put detail in linked docs
alwaysApply: true
---

AGENTS.md is an index, not a manual. If an instruction needs more than a few lines, add it under `docs/agents/` and link it.

Do not paste long style guides, component catalogs, or ticket history into AGENTS.md. Agents follow a short file more reliably than a long one.

When two docs disagree, the more specific linked doc wins: DESIGN.md for visual values, CODE_STYLE.md for structure, BRANCHING.md for git.
